FEATURE: Currency History

FieldValue
Version20261026 V1
DescriptionReturns a currency's stored rate history and summary statistics over optional bounds.
Depends OnFEATURE-AppServer.md, DATABASE.md
ProvidesGET /history/{code}
Consumescreate_app(), rates repository operations

Purpose

Return a currency's publication points and min, max, and mean statistics over an optional inclusive date range.

Trigger and workflow

A caller requests a currency history with optional start and end dates. Malformed bounds return 422. Return points in ascending date order and preserve each published rate string. Return 404 if the currency has no stored history at all, including EUR. If it has history but no points in the selected range, return count zero, null min/max/mean, and an empty points list.

Compute minimum and maximum by numeric value. Compute the exact mean using Decimal and round half-even to six decimal places.

Database Interface

  • FEATURE-RATE-004 — read: list a currency's rates within optional inclusive bounds - supplies: currency, start_date, end_date - returns: date, currency, rate
  • FEATURE-RATE-005 — read: determine whether the currency has any stored rate - supplies: none - returns: date, currency, rate

Programmatic Acceptance

=== AC history-range-and-statistics ===
Intent: The history endpoint returns bounded points and statistics derived from the seeded rates.

Requires: python-package=fastapi; scope=test
Requires: python-package=httpx2; scope=test

from decimal import Decimal, ROUND_HALF_EVEN from app_server.testing import web_client from persistence.testing import db_session

currency = "QAK" dates = ["2099-09-01", "2099-09-02", "2099-09-03"] rates = ["1.1", "1.3", "1.2"] start = dates[0] end = dates[2]

with db_session() as db: for date, rate in zip(dates, rates): db.rates.upsert(date=date, currency=currency, rate=rate)

response = web_client().get(f"/history/{currency}", params={"start": start, "end": end}) body = response.json() expected_mean = (sum((Decimal(rate) for rate in rates), Decimal(0)) / len(rates)).quantize( Decimal("0.000001"), rounding=ROUND_HALF_EVEN ) assert response.status_code == 200 assert body["currency"] == currency assert body["base"] == "EUR" assert [point["date"] for point in body["points"]] == dates assert [point["rate"] for point in body["points"]] == rates assert body["count"] == len(rates) assert body["min"] == min(rates, key=Decimal) assert body["max"] == max(rates, key=Decimal) assert body["mean"] == f"{expected_mean:.6f}" === END AC history-range-and-statistics ===
