Programmatic Acceptance

=== AC rate-upsert-round-trip ===
Intent: An upsert stores the supplied published rate text and a separate get reads it back.

from persistence.testing import db_session

day = "2099-01-02" currency = "XTS" published_rate = "1.2300"

with db_session() as db: db.rates.upsert(date=day, currency=currency, rate=published_rate) stored = db.rates.get(date=day, currency=currency)

assert stored is not None assert stored.date == day assert stored.currency == currency assert stored.rate == published_rate === END AC rate-upsert-round-trip ===

=== AC rate-list-filters-and-order ===
Intent: The list operation returns supplied rows in ascending date and currency order and applies its declared filters.

from persistence.testing import db_session

first_day = "2099-01-02" second_day = "2099-01-03" currency = "XTS" first_rate = "1.2300" second_rate = "1.24"

with db_session() as db: db.rates.upsert(date=second_day, currency=currency, rate=second_rate) db.rates.upsert(date=first_day, currency=currency, rate=first_rate) rows = db.rates.list(currency=currency, start_date=first_day, end_date=second_day)

assert [(row.date, row.currency, row.rate) for row in rows] == [ (first_day, currency, first_rate), (second_day, currency, second_rate), ] === END AC rate-list-filters-and-order ===

=== AC rate-delete-round-trip ===
Intent: Deleting a rate removes the supplied date and currency record.

from persistence.testing import db_session

day = "2099-01-04" currency = "XTS" published_rate = "1.250"

with db_session() as db: db.rates.upsert(date=day, currency=currency, rate=published_rate) db.rates.delete(date=day, currency=currency) stored = db.rates.get(date=day, currency=currency)

assert stored is None === END AC rate-delete-round-trip ===

Guardrails

  • Store rates exactly as published text; do not normalize decimal formatting or store rates as floating point.
  • A stored rate is uniquely identified by its publication date and currency.
  • Application code reaches SQLite only through the generated persistence package.
  • Resolve the database location from DATABASE_URL, then DATABASE_PATH, then data/app.db.
