ARCHITECTURE: FxRates

Module ownership

BoundaryOwnerResponsibility
ConfigurationconfigReads DATABASE_URL, then DATABASE_PATH, then data/app.db.
Persistencegenerated persistence packageOwns database connections and declared repository operations. Application modules must not open drivers or issue SQL directly.
CLIcliParses commands, invokes feature services, and writes command output and diagnostics.
APIapp_serverCreates the FastAPI application and delegates route behavior to feature services.
ECB fetchCLI fetch serviceDownloads and extracts ECB data, then delegates CSV loading to shared load behavior.

The root fxrates executable delegates to cli.main. Persisted ECB rates retain their published text; arithmetic uses decimal.Decimal.
