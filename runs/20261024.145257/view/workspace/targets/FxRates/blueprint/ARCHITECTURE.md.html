FieldValue
Version20261024 V1
DescriptionDefines the application modules and their ownership boundaries.

System Structure

The application is a Python 3.11+ command-line program and JSON HTTP API. The root fxrates executable delegates to cli.main. The API is created by app_server.main.create_app() and served by uvicorn. Features call the generated persistence package for all database access.

Module Ownership

BoundaryOwnerAllowed access
ConfigurationconfigReads DATABASE_URL, then DATABASE_PATH, then the data/app.db default.
Persistencegenerated persistence packageOpens the configured database and performs declared repository operations.
CLIcliParses commands and arguments, invokes feature services, and writes command output and diagnostics.
APIapp_serverDefines FastAPI routes and delegates data operations to feature services.
ECB fetch integrationCLI fetch serviceDownloads and extracts the ECB archive; passes its CSV to the shared loading behavior.

No application module may open a database driver or issue SQL directly. Persisted rates use their published ECB text; arithmetic uses decimal.Decimal.
