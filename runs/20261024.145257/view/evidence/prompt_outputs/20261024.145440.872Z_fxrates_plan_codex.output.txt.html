## Persistence Boundary

| Boundary | Rule |
|----------|------|
| Raw storage access | Only the generated `persistence/` package reaches SQLite. |
| Caller dependency | Features call the repository operations declared below; SQL and table details stay inside the persistence boundary. |
| Rate representation | `rate` is stored as the ECB-published text. Arithmetic conversion to `Decimal` happens in application services. |
| Initialization | The CLI initializes the rates store through its declared repository operation; callers do not open a database driver or issue DDL. |

## Programmatic Acceptance

=== AC rates-upsert ===
Intent: Upserting a rate stores its published text and replaces the matching date and currency row.

from persistence.testing import db_session

date = "2099-01-02"
currency = "ZZZ"
published = "0.943"
replacement = "0.944"
with db_session() as db:
    db.rates.upsert(date=date, currency=currency, rate=published)
    first = db.rates.get(date=date, currency=currency)
    assert first.rate == published
    db.rates.upsert(date=date, currency=currency, rate=replacement)
    stored = db.rates.get(date=date, currency=currency)
    assert stored.rate == replacement
=== END AC rates-upsert ===
