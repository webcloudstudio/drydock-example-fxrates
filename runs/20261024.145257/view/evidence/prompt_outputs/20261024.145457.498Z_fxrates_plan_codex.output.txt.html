# ARCHITECTURE: FxRates

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Defines the application modules and their ownership boundaries. |

## Questions

- None.

## System Structure

The application is a Python 3.11+ command-line program and JSON HTTP API. The root `fxrates` executable delegates to `cli.main`. The API is created by `app_server.main.create_app()` and served by uvicorn. Features call the generated `persistence` package for all database access.

## Module Ownership

| Boundary | Owner | Allowed access |
|----------|-------|----------------|
| Configuration | `config` | Reads `DATABASE_URL`, then `DATABASE_PATH`, then the `data/app.db` default. |
| Persistence | generated `persistence` package | Opens the configured database and performs declared repository operations. |
| CLI | `cli` | Parses commands and arguments, invokes feature services, and writes command output and diagnostics. |
| API | `app_server` | Defines FastAPI routes and delegates data operations to feature services. |
| ECB fetch integration | CLI fetch service | Downloads and extracts the ECB archive; passes its CSV to the shared loading behavior. |

No application module may open a database driver or issue SQL directly. Persisted rates use their published ECB text; arithmetic uses `decimal.Decimal`.

## Technology Stack

| Technology | Use |
|------------|-----|
| Python | Application language and project test suite. |
| FastAPI | JSON HTTP API. |
| SQLite | Local relational store, accessed only through the generated persistence package. |
| CLI | Root `fxrates` executable with `init`, `load`, `fetch`, and `serve` commands. |
| ECB reference rates | ECB history CSV obtained from the published ZIP archive. |
| Shell | POSIX-compatible command and test runners. |
| pytest | Automated project test suite. |
| uvicorn | Runs the FastAPI application on localhost. |

# FEATURE: CLI Load

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Loads ECB history CSV files after validating each complete file. |
| Depends On  | DATABASE.md, ARCHITECTURE.md, FEATURE-CLI-Init.md |
| Provides    | fxrates load |
| Consumes    | rates repository operations |

## Questions

- None.

## Purpose

`fxrates load <csv>` validates the whole ECB history file before writing, stores each non-`N/A` published rate as text, replaces matching date and currency rows, and reports the dates and rates stored from the file.

## Workflow

The CSV header starts with `Date`, followed by three-letter uppercase currency codes; a final empty field from the ECB trailing comma is ignored. Each row has a valid, unique calendar date and one value per currency. `N/A` is skipped; other values must match `[0-9]+(\.[0-9]+)?` and be nonzero. Wrong field counts, malformed or repeated dates, and invalid values reject the entire file without writes. An unreadable path is an operational failure.

Success writes:

- `dates,rates`
- The number of dates containing at least one stored rate and the number of rates stored from the input file.

Exit status is 0 on success, 1 when the file cannot be read, and 3 for a rejected file. Failure writes no standard output.

## Database Interface

- `FEATURE-RATE-001` — write: replace a rate - supplies: `date`, `currency`, `rate` - returns: `date`, `currency`, `rate`
- `FEATURE-RATE-005` — read: list all rates - supplies: no fields - returns: `date`, `currency`, `rate`

## Questions

- None.

## Purpose

`fxrates fetch` downloads the ECB history ZIP, extracts `eurofxref-hist.csv`, and processes it using the same complete-file validation and atomic loading behavior as `fxrates load`.

## Workflow

Download from the ECB history archive URL, extract the named CSV, and pass the extracted content through the shared loader. Successful output follows the load command contract. Download or extraction failures return operational status 1 and produce no standard output.

Tests replace the download operation with a stub; the test suite does not open a network connection.

## Programmatic Acceptance

# FEATURE: CLI Serve

| Provides    | fxrates serve |
| Consumes    | app_server.main:app |

## Questions

- None.

## Purpose

`fxrates serve [--port <n>]` runs uvicorn in the foreground on `127.0.0.1`, using port 8000 by default, until stopped.

## Workflow

The command accepts an optional integer port. An invalid port argument is a usage error. The server binds only to `127.0.0.1`, serves the API application, and terminates cleanly on SIGTERM.
