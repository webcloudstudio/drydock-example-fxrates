FEATURE: Currency History

FieldValue
Version20261024 V1
DescriptionReturns a currency's stored rate history and summary statistics.
Depends OnDATABASE.md
ProvidesGET /history/{code}
Consumesrates repository operations

Purpose

Return ascending publication-date points for a currency, optionally bounded by inclusive start and end dates. Rates, minimum, and maximum preserve stored text. Compute the exact mean with decimal arithmetic and half-even rounding to six decimal places. When the selected range has no points, return an empty points list, count zero, and null statistics. Return 404 when the currency has no stored rate at all.

Database Interface

  • FEATURE-RATE-002 — read: list rates with optional date and currency filters - supplies: date, currency - returns: id, date, currency, rate

Programmatic Acceptance

Requires: python-package=httpx; scope=test

=== AC history-range ===
Intent: The history endpoint returns the stored rate as a point for an inclusive single-date range.

from persistence.testing import db_session from app_server.testing import web_client

publication = "2099-01-02" currency = "ZZZ" rate = "1.2300" with db_session() as db: db.rates.upsert(date=publication, currency=currency, rate=rate)

response = web_client().get( f"/history/{currency}", params={"start": publication, "end": publication} ) body = response.json() assert response.status_code == 200 assert body["currency"] == currency assert body["count"] == 1 assert body["points"] == [{"date": publication, "rate": rate}] assert body["min"] == rate assert body["max"] == rate assert body["mean"] == "1.230000" === END AC history-range ===
