# FEATURE: CLI Load

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Loads validated ECB history files into the rates store and reports the imported totals. |
| Depends On  | DATABASE.md |
| Provides    | fxrates load |
| Consumes    | rates repository operations |

## Questions

- None.

## Purpose

Load an ECB euro reference history CSV into the rates store. A rejected file must leave stored data unchanged.

## Workflow

1. Read the requested CSV file.
2. Validate the complete file before writing any rates.
3. For each row, store every valid rate as its exact published text; skip `N/A`.
4. Replace an existing rate with the same date and currency.
5. Report `dates,rates`, followed by the number of dates with at least one stored rate and the number of rates stored from this file.

The header begins with `Date`; subsequent fields are three-letter uppercase currency codes. Ignore the trailing empty field produced by the ECB's trailing comma. Dates must be real, unique `YYYY-MM-DD` dates within the file. Each row must have the expected field count. Rate values must match `[0-9]+(\.[0-9]+)?` and be nonzero, or be `N/A`.

A malformed row, repeated or invalid date, or invalid rate rejects the whole file before the first write, returning exit code 3. An unreadable file returns exit code 1. Failures produce no standard output and one diagnostic line on standard error.

## Database Interface

- `FEATURE-RATE-001` — write: store or replace a rate - supplies: `date`, `currency`, `rate` - returns: `id`, `date`, `currency`, `rate`

## Programmatic Acceptance

=== AC load-valid-file ===
Intent: A valid staged ECB file loads successfully and its rows can be read back through the rates repository.

from cli.testing import cli_runner
from persistence.testing import db_session

code, out, err = cli_runner("load", "sources/eurofxref-hist_2025-02-03_04.csv")
assert code == 0

with db_session() as db:
    rows = db.rates.list(date="2025-02-04")
    by_currency = {row.currency: row.rate for row in rows}
    assert len(rows) == 8
    assert by_currency["USD"] == "1.0335"
    assert by_currency["CNY"] == "7.4943"
=== END AC load-valid-file ===

=== AC load-rejects-whole-file ===
Intent: A file containing an invalid rate is rejected without storing any of its rows.

from cli.testing import cli_runner
from persistence.testing import db_session

code, out, err = cli_runner("load", "sources/eurofxref-hist_bad.csv")
assert code == 3

with db_session() as db:
    assert db.rates.list(date="2025-02-03") == []
=== END AC load-rejects-whole-file ===

## User Acceptance

- None.

## Guardrails

- Validate every row before the first write.
- Preserve published rate text and never store `N/A`.
- Replace existing values for the same date and currency.
- Do not read the harness or data files from application code.
- Access rates only through the generated persistence package.

## Questions

- None.

## Behavior

The executable returns exit code 0 on success. Unknown commands, wrong argument counts, and a non-integer `--port` return exit code 2. Unreadable load files and fetch download failures return exit code 1. A failing command writes no standard output and exactly one diagnostic line to standard error. Diagnostic wording is concise and is not part of the response contract.

# FEATURE: CLI Fetch

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Downloads and loads the ECB reference history archive with the same rules as the load command. |
| Depends On  | FEATURE-CLI-Load.md |
| Provides    | fxrates fetch |
| Consumes    | fxrates load |

## Questions

- None.

## Workflow

Fetch downloads `https://www.ecb.europa.eu/stats/eurofxref/eurofxref-hist.zip` using Python's standard-library HTTPS support, extracts `eurofxref-hist.csv`, and loads it using the same validation, replacement, and reporting rules as `fxrates load`. Tests stub the download and must not use the network. Download failures return exit code 1.

## Programmatic Acceptance

=== AC fetch-loads-stubbed-archive ===
Intent: Fetch loads the CSV supplied by a stubbed archive download without opening a network connection.

import io
import zipfile
from unittest.mock import patch
from cli.testing import cli_runner
from persistence.testing import db_session

csv_bytes = b"Date,USD,\n2099-01-02,1.2300,\n"
archive = io.BytesIO()
with zipfile.ZipFile(archive, "w") as zipped:
    zipped.writestr("eurofxref-hist.csv", csv_bytes)

with patch("urllib.request.urlopen", return_value=io.BytesIO(archive.getvalue())):
    code, out, err = cli_runner("fetch")
assert code == 0

with db_session() as db:
    rows = db.rates.list(date="2099-01-02", currency="USD")
    assert len(rows) == 1
    assert rows[0].rate == "1.2300"
=== END AC fetch-loads-stubbed-archive ===

=== AC fetch-download-failure ===
Intent: A failed stubbed download returns the operational failure exit status.

from unittest.mock import patch

with patch("urllib.request.urlopen", side_effect=OSError):
    code, out, err = cli_runner("fetch")
assert code == 1
=== END AC fetch-download-failure ===

## User Acceptance

- None.

## Guardrails

- Tests must stub the archive download and make no network connection.
- Extract the named `eurofxref-hist.csv` member and apply the load command's validation rules.

## Questions

- None.

## Routes

### GET /health

Returns JSON `{"status": "ok"}` with HTTP 200.

### GET /stats

Returns the number of distinct publication dates and stored rates, plus the first and last publication dates. When the store is empty, `first` and `last` are null. Statistics are derived from stored rows and reflect loads completed while the server is running.

## Database Interface

- `FEATURE-RATE-002` — read: list rates with optional equality filters - supplies: `date`, `currency` - returns: `id`, `date`, `currency`, `rate`
