## Programmatic Acceptance

=== AC rates-upsert ===
Intent: The rates upsert operation stores the supplied published text and replaces the row for the same date and currency.

from persistence.testing import db_session

date = "2099-01-02"
currency = "ZZZ"
rate = "1.2300"
with db_session() as db:
    db.rates.upsert(date=date, currency=currency, rate=rate)
    rows = db.rates.list(date=date, currency=currency)
    assert len(rows) == 1
    assert (rows[0].date, rows[0].currency, rows[0].rate) == (date, currency, rate)
    replacement = "1.2400"
    db.rates.upsert(date=date, currency=currency, rate=replacement)
    rows = db.rates.list(date=date, currency=currency)
    assert len(rows) == 1
    assert rows[0].rate == replacement
=== END AC rates-upsert ===

=== AC rates-list ===

from persistence.testing import db_session

=== AC rates-delete ===
Intent: The rates delete operation removes only the row selected by its date and currency key.

from persistence.testing import db_session

date = "2099-01-04"
currency = "WWW"
rate = "3.75"
with db_session() as db:
    db.rates.upsert(date=date, currency=currency, rate=rate)
    deleted = db.rates.delete(date=date, currency=currency)
    assert deleted is not None
    assert (deleted.date, deleted.currency) == (date, currency)
    assert db.rates.list(date=date, currency=currency) == []
=== END AC rates-delete ===

## User Acceptance

## Guardrails

- Store every rate as the exact published text; do not store rates as floating-point values.
- The natural key is the pair (`date`, `currency`); loading a repeated key replaces its stored rate.
- All database access goes through the generated persistence package.
