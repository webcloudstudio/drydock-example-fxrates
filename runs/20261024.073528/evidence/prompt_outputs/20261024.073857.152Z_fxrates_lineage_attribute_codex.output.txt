<requirement name="build-service-stack" stories="foundation">
Implement in Python 3.11 or newer with FastAPI, served by uvicorn, over SQLite.
</requirement>
<requirement name="rates-schema" stories="data_schema">
| `rates` | `date` text `YYYY-MM-DD`, `currency` text, `rate` text | primary key (`date`, `currency`) |
</requirement>
<requirement name="load-ecb-history" stories="data_load">
`fxrates load <csv>` | Loads an ECB history file (rules below). | `dates,rates`, then the number of dates and of rates stored from the file.
</requirement>
<requirement name="fetch-ecb-history" stories="data_fetch">
`fxrates fetch` | Downloads `https://www.ecb.europa.eu/stats/eurofxref/eurofxref-hist.zip`, extracts `eurofxref-hist.csv`, and loads it as `load`. | As `load`.
</requirement>
<requirement name="provide-cli-commands" stories="cli_interface">
The product is an executable named `fxrates` at the application root.
</requirement>
<requirement name="serve-health-stats-currencies" stories="api_overview">
| `GET /health` | `{"status": "ok"}` |
</requirement>
<requirement name="query-effective-and-latest-rates" stories="api_rates">
**Effective date.** The ECB publishes on working days only. A request for date `D` uses the latest publication date on or before `D`. If none exists, the response is `404`.
</requirement>
<requirement name="convert-currency" stories="api_conversion">
`GET /convert?from=<code>&to=<code>&amount=<amount>[&date=<date>]` | `{"date": <effective date>, "from": <code>, "to": <code>, "amount": <amount>, "rate": <rate>, "result": <result>}`. Without `date`, the latest publication date is used.
</requirement>
<requirement name="return-currency-history" stories="api_history">
`GET /history/{code}[?start=<date>][&end=<date>]` | `{"currency": <code>, "base": "EUR", "count": <n>, "min": <rate>, "max": <rate>, "mean": <mean>, "points": [{"date": <date>, "rate": <rate>}, ...]}` for the publication dates from `start` through `end` inclusive, ascending. Both bounds are optional. With no points, `count` is `0`, `min`, `max`, and `mean` are `null`, and `points` is `[]`.
</requirement>
<requirement name="provide-project-test-suite" stories="project_tests">
The completed application provides a POSIX-compatible `bin/test.sh` that runs its own pytest suite from the application root and exits zero only when every test passes.
</requirement>
