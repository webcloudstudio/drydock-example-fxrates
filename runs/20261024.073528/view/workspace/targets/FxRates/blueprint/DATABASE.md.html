Programmatic Acceptance

=== AC rates-list ===
Intent: Listing returns the rows created through the declared repository interface.

from persistence.testing import db_session

with db_session() as db: date = "2099-01-02" currency = "QAZ" rate = "1.234" db.rates.upsert(date=date, currency=currency, rate=rate) rows = db.rates.list(date=date, currency=currency) assert len(rows) == 1 assert rows[0].date == date assert rows[0].currency == currency assert rows[0].rate == rate === END AC rates-list ===

=== AC rates-upsert ===
Intent: Upserting the same date and currency replaces the stored rate.

from persistence.testing import db_session

with db_session() as db: date = "2099-01-03" currency = "QAZ" first_rate = "1.234" replacement_rate = "1.235" db.rates.upsert(date=date, currency=currency, rate=first_rate) db.rates.upsert(date=date, currency=currency, rate=replacement_rate) rows = db.rates.list(date=date, currency=currency) assert len(rows) == 1 assert rows[0].date == date assert rows[0].currency == currency assert rows[0].rate == replacement_rate === END AC rates-upsert ===

=== AC rates-delete ===
Intent: Deleting a matching date and currency removes that rate.

from persistence.testing import db_session

with db_session() as db: date = "2099-01-04" currency = "QAZ" rate = "1.234" db.rates.upsert(date=date, currency=currency, rate=rate) removed = db.rates.delete(date=date, currency=currency) assert removed.date == date assert removed.currency == currency assert db.rates.list(date=date, currency=currency) == [] === END AC rates-delete ===

User Acceptance

  • None.

Guardrails

  • Preserve published rates as text; do not convert them to floating point during storage.
  • Keep the (date, currency) natural key unique so replacement is atomic and unambiguous.
  • All runtime database access goes through the generated persistence package.
