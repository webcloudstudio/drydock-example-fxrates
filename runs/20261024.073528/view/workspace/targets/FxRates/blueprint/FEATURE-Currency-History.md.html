FEATURE: Currency History

FieldValue
Version20261024 V1
DescriptionRetrieves a currency's published rate history and summary statistics.
Depends OnARCHITECTURE.md, DATABASE.md
ProvidesGET /history/{code}
Consumesrates.list

Purpose

Return a currency's rates by publication date in ascending order. Optional start and end bounds are inclusive. Return the number of points, the stored text rates with their dates, minimum and maximum by numeric value, and the exact mean rounded half-even to six decimal places. When the range has no points for a currency that has stored rates, return count zero, null min, max, and mean, and an empty points list. A currency with no stored rates, including EUR, returns 404. Malformed or impossible bounds return 422.

Database Interface

  • None — persistence is owned by FEATURE-CLI.md, FEATURE-Rate-Loading.md.

Intent: History returns stored points in ascending order and reports their count.

from app_server.testing import web_client from persistence.testing import db_session

with db_session() as db: first_date = "2099-01-02" second_date = "2099-01-03" currency = "QAZ" first_rate = "1.2" second_rate = "1.3" db.rates.upsert(date=second_date, currency=currency, rate=second_rate) db.rates.upsert(date=first_date, currency=currency, rate=first_rate)

client = web_client() response = client.get(f"/history/{currency}") assert response.status_code == 200 body = response.json() assert body["currency"] == currency assert body["base"] == "EUR" assert body["count"] == 2 assert body["points"] == [ {"date": first_date, "rate": first_rate}, {"date": second_date, "rate": second_rate}, ] === END AC history-points ===
