## Schema

## `rates`

| Field | Type | Notes |
|-------|------|-------|
| date | TEXT NOT NULL | ECB publication date in YYYY-MM-DD form. |
| currency | TEXT NOT NULL | Three-letter uppercase currency code. |
| rate | TEXT NOT NULL | Rate exactly as published by the ECB. |
| key | INTEGER PK | Internal row key. |

- UNIQUE (date, currency)

## Database Interface

- `FEATURE-RATE-001` — write: replace a rate - supplies: `date`, `currency`, `rate` - returns: `date`, `currency`, `rate`
- `FEATURE-RATE-002` — read: list rates for an effective date - supplies: `date` - returns: `date`, `currency`, `rate`
- `FEATURE-RATE-003` — read: get the latest publication date - supplies: — - returns: `date`
- `FEATURE-RATE-004` — read: retrieve rate records for derived statistics - supplies: — - returns: `date`, `currency`, `rate`
- `FEATURE-RATE-005` — read: list currencies with stored rates - supplies: — - returns: `currency`
- `FEATURE-RATE-006` — read: list currency rates within inclusive date bounds - supplies: `currency`, `start_date`, `end_date` - returns: `date`, `currency`, `rate`

## Programmatic Acceptance

=== AC rates-replace-rate ===
Intent: Upserting a rate stores its published text and replaces the same date and currency.

from persistence.testing import db_session

date = "2099-01-02"
currency = "ZZZ"
published_rate = "0.943"
with db_session() as db:
    db.rates.replace_rate(date=date, currency=currency, rate=published_rate)
    row = db.rates.get(date=date, currency=currency)
    assert row is not None
    assert row.rate == published_rate
    replacement = "0.944"
    db.rates.replace_rate(date=date, currency=currency, rate=replacement)
    row = db.rates.get(date=date, currency=currency)
    assert row is not None
    assert row.rate == replacement
=== END AC rates-replace-rate ===

=== AC rates-by-date ===
Intent: Listing rates by date returns the selected records in currency order.

from persistence.testing import db_session

date = "2099-01-03"
with db_session() as db:
    db.rates.replace_rate(date=date, currency="ZZZ", rate="1.2")
    db.rates.replace_rate(date=date, currency="AAA", rate="2.3")
    rows = db.rates.by_date(date=date)
    assert [row.currency for row in rows] == ["AAA", "ZZZ"]
    assert all(row.date == date for row in rows)

=== AC rates-history ===
Intent: Currency history returns only matching rows in inclusive bounds, ordered by date.

from persistence.testing import db_session

with db_session() as db:
    db.rates.replace_rate(date="2099-04-01", currency="ZZZ", rate="1.1")
    db.rates.replace_rate(date="2099-04-02", currency="ZZZ", rate="1.2")
    db.rates.replace_rate(date="2099-04-03", currency="AAA", rate="1.3")
    rows = db.rates.history(
        currency="ZZZ", start_date="2099-04-01", end_date="2099-04-02"
    )
    assert [row.date for row in rows] == ["2099-04-01", "2099-04-02"]
    assert all(row.currency == "ZZZ" for row in rows)

## Guardrails

- Store rates as text exactly as published; do not normalize their spelling or use floating point.
- Enforce the natural key `(date, currency)` so loading can replace matching rates.
- Application code accesses SQLite only through the shipped persistence library.
- Resolve database configuration from `DATABASE_URL`, then `DATABASE_PATH`, then `data/app.db`.
