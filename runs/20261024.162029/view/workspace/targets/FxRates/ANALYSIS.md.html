Planning Instructions

Delivery Shape

A local command-line loader initializes SQLite, imports ECB history, and can fetch the published archive. A FastAPI JSON service reads the same persisted rates and serves health, summary, currency, date-rate, conversion, and history requests. The required flow is initialize, load history, then serve requests; fetch is an additional import path. The supplied grader runs the CLI, starts the API on a free local port, and checks its responses.

Test and Acceptance Strategy

Write focused tests for each story: command behavior and loader rejection/replacement, endpoint response shapes and statuses, effective-date resolution, and exact decimal rounding. Stub the archive download in fetch tests and make no network connection. Keep these tests bounded to the story they cover.

The sole terminal verification story runs the complete automated suite and declares Suite: full; it depends on every implementation story. sources/run.sh is the supplied end-to-end acceptance command and is checked separately by Sea Trials.

Sequencing and Dependencies

Implement initialization and the validated loader before fetch and persistent API reads. Implement effective-date selection before rates and conversion behavior that relies on it. Build focused tests alongside their stories. Stage the CSV fixtures and harness before terminal verification. Do not add a database driver path outside the shipped persistence library.
