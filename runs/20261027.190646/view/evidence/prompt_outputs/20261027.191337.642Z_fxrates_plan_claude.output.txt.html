# FEATURE: Operational Failures

| Field | Value |
|-------|-------|
| Version | 20261027 V1 |
| Description | Proves that an unreadable load file and a failed fetch download each exit 1 with one stderr line, empty stdout and an unchanged database. |
| Depends On | FEATURE-LoadAtomic.md, FEATURE-Fetch.md, FEATURE-CliFoundation.md |
| Provides | fxrates exit code 1 diagnostics |
| Consumes | fxrates load, fxrates fetch |

## Questions

- None.

## Purpose

Operational failures are exit code `1`: a `load` file that cannot be read, and a `fetch` download that fails. This story assembles `load` and `fetch` and proves the seams between them and the dispatcher. Each failure writes nothing to standard output, writes exactly one diagnostic line to standard error, and leaves stored rates untouched. Any seam that breaks this is fixed here.

## Behavior

| Trigger | Exit | Stdout | Stderr | Database |
|---------|------|--------|--------|----------|
| `fxrates load <path>` where `<path>` does not exist or cannot be read | 1 | empty | one line | unchanged |
| `fxrates fetch` where `ecb.download_history()` raises `OperationalError` | 1 | empty | one line | unchanged |

Tests replace `ecb.download_history` with a stub; no test opens a network connection.

## Database Interface

- None — persistence is owned by DATABASE.md.

=== AC failures-fetch-download ===
Intent: When the stubbed download raises OperationalError, fetch exits 1 with empty stdout and one stderr line, and stored rates are unchanged.
Requires: executable=python3; scope=test

import ecb
from cli.testing import cli_runner
from persistence.testing import db_session

try:
    from cli.errors import OperationalError
except ImportError:
    from cli import OperationalError


def failing_download():
    raise OperationalError("download failed")


original = ecb.download_history
ecb.download_history = failing_download
try:
    with db_session() as db:
        before = [(r.date, r.currency, r.rate) for r in db.rates.list_all()]
        code, out, err = cli_runner("fetch")
        assert code == 1
        assert out == ""
        assert len(err.strip().splitlines()) == 1
        after = [(r.date, r.currency, r.rate) for r in db.rates.list_all()]
        assert after == before
finally:
    ecb.download_history = original

# FEATURE: Serve

| Field | Value |
|-------|-------|
| Version | 20261027 V1 |
| Description | Implements fxrates serve, running uvicorn on 127.0.0.1 in the foreground and stopping cleanly on SIGTERM. |

| Provides | fxrates serve |
| Consumes | GET /health, fxrates usage validation, cli.main |

## Questions

- None.

## Purpose

`fxrates serve [--port <n>]` serves the HTTP API from `app_server.main:app` with uvicorn until stopped.

## Behavior

| Aspect | Rule |
|--------|------|
| Host | Bound only to `127.0.0.1`. |
| Port | `--port <n>`; default `8000`. A non-integer port is rejected earlier by usage validation with exit 2. |
| Foreground | The command runs in the foreground until stopped. |
| SIGTERM | uvicorn shuts down gracefully and the process exits 0. |
| Stdout | Nothing is required. |
| Schema | Serving never initializes the schema. |

The handler is `cli/commands/serve.py` with `run(args) -> int`.

## Database Interface

- None — persistence is owned by DATABASE.md.

## Programmatic Acceptance

=== AC serve-health-reachable ===
Intent: Starting fxrates serve on a free local port makes GET /health answer 200 with the status ok body at 127.0.0.1 within a deadline, and the child is always terminated and reaped.
Requires: executable=python3; scope=test

import json
import os
import signal
import socket
import subprocess
import sys
import tempfile
import time
import urllib.request

sock = socket.socket()
sock.bind(("127.0.0.1", 0))
port = sock.getsockname()[1]
sock.close()

with tempfile.TemporaryDirectory() as tmp:
    env = {**os.environ, "DATABASE_URL": os.path.join(tmp, "serve.db")}
    log = open(os.path.join(tmp, "server.log"), "w+")
    child = subprocess.Popen(
        ["./fxrates", "serve", "--port", str(port)],
        stdout=log, stderr=subprocess.STDOUT, env=env,
    )
    try:
        url = f"http://127.0.0.1:{port}/health"
        deadline = time.time() + 30
        status = None
        body = None
        while time.time() < deadline:
            if child.poll() is not None:
                break
            try:
                with urllib.request.urlopen(url, timeout=2) as r:
                    status, body = r.status, json.loads(r.read())
                break
            except Exception:
                time.sleep(0.25)
        log.seek(0)
        print(log.read(), file=sys.stderr)
        assert child.poll() is None, "server exited before answering"
        assert status == 200
        assert body == {"status": "ok"}
    finally:
        if child.poll() is None:
            child.terminate()
        try:
            child.wait(timeout=15)
        except subprocess.TimeoutExpired:
            child.kill()
            child.wait()
        log.close()
=== END AC serve-health-reachable ===

=== AC serve-sigterm-clean ===
Intent: Sending SIGTERM to a running server stops it within a deadline with exit status 0.
Requires: executable=python3; scope=test

import os
import signal
import socket
import subprocess
import sys
import tempfile
import time
import urllib.request

sock = socket.socket()
sock.bind(("127.0.0.1", 0))
port = sock.getsockname()[1]
sock.close()

with tempfile.TemporaryDirectory() as tmp:
    env = {**os.environ, "DATABASE_URL": os.path.join(tmp, "serve.db")}
    child = subprocess.Popen(
        ["./fxrates", "serve", "--port", str(port)],
        stdout=subprocess.DEVNULL, stderr=subprocess.PIPE, env=env,
    )
    try:
        url = f"http://127.0.0.1:{port}/health"
        deadline = time.time() + 30
        ready = False
        while time.time() < deadline and child.poll() is None:
            try:
                with urllib.request.urlopen(url, timeout=2) as r:
                    ready = r.status == 200
                break
            except Exception:
                time.sleep(0.25)
        assert ready, "server never became ready"
        child.send_signal(signal.SIGTERM)
        code = child.wait(timeout=20)
        err = child.stderr.read().decode("utf-8", "replace")
        print(err, file=sys.stderr)
        assert code == 0
    finally:
        if child.poll() is None:
            child.kill()
            child.wait()
        child.stderr.close()
=== END AC serve-sigterm-clean ===
