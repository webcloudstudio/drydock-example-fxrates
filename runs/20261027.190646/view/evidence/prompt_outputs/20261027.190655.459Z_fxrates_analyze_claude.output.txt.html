# COMPASS: drydock FxRates Uat Case

## Compass
A currency rates service for developers and callers who need ECB euro reference rates. A CLI loads the ECB published history into a local SQLite store, and a JSON HTTP API answers rate-by-date, conversion, and currency-history questions with exact decimal results.

## Constraints
- Python 3.11 or newer; FastAPI served by uvicorn; SQLite.
- Tests run under pytest with FastAPI TestClient; offline with network denied.
- All database access goes through the generated persistence package; application code never opens a driver or authors SQL.
- `fxrates init` is the only initializer; application startup opens the store without initializing it.
- `fetch` downloads only from the official ECB URL; the harness uses no network beyond 127.0.0.1.

## Guardrails
- Never store or compute rates as floating point; use text storage and Python `decimal`.
- Never read `sources/run.sh` or embed a known answer in application code.
- A rejected ECB file changes nothing: validate the whole file before the first write.
- Never drop tables, delete records, or migrate existing definitions in init.
- Never delete or replace the configured working application database in tests or setup.
- Standard error and error-response bodies are not part of the contract; keep stdout empty on failure.
