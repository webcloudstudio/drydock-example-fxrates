Purpose

This is the terminal story. Every other story has closed before it runs. It adds no behavior; it proves the assembled application passes its own pytest suite through bin/test.sh and passes the supplied grader sources/run.sh, and that application code reaches the database only through the shipped persistence package.

Sequence

  1. Confirm the executable fxrates exists at the application root.
  2. Run sh bin/test.sh and require exit status 0.
  3. Run sh sources/run.sh and require exit status 0.
  4. Scan application Python modules for direct database driver imports outside persistence/.

Database Interface

  • None — persistence is owned by DATABASE.md and exercised through the commands and routes under test.

=== AC verification-persistence-boundary ===
Intent: No application module outside the shipped persistence package imports a database driver, so all access goes through the persistence library.
Requires: executable=python3; scope=test

import ast import os

skip = {".venv", "venv", "persistence", "tests", "sources", ".git", "pycache", "node_modules", "blueprint"} drivers = {"sqlite3", "psycopg", "psycopg2", "sqlalchemy"} offenders = [] scanned = 0

for root, dirs, files in os.walk("."): dirs[:] = [d for d in dirs if d not in skip] for name in files: if not name.endswith(".py"): continue path = os.path.join(root, name) with open(path, encoding="utf-8") as handle: tree = ast.parse(handle.read(), filename=path) scanned += 1 for node in ast.walk(tree): if isinstance(node, ast.Import): mods = [alias.name for alias in node.names] elif isinstance(node, ast.ImportFrom): mods = [node.module or ""] else: continue for mod in mods: if mod.split(".")[0] in drivers: offenders.append((path, mod))

print(f"scanned {scanned} modules, {len(offenders)} driver imports") assert scanned > 0 assert offenders == [] === END AC verification-persistence-boundary ===
