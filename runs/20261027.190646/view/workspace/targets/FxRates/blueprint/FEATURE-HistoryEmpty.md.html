FEATURE: History Empty

FieldValue
Version20261027 V1
DescriptionGET /history/{code} for a known currency with no points in range returns count 0, null statistics and no points.
Depends OnFEATURE-History.md
ProvidesGET /history/{code} empty
ConsumesGET /history/{code}

Purpose

A currency with stored rates but none inside the requested period is a valid, empty answer rather than an error.

Routes

RouteConditionResponse
GET /history/{code}The range holds no points for a currency with stored rates200 {"currency", "base": "EUR", "count": 0, "min": null, "max": null, "mean": null, "points": []}

Behavior

  • No division is attempted on an empty set; min, max and mean are JSON null.
  • The same applies when start is after end.

Database Interface

  • None — persistence is owned by DATABASE.md.

=== AC history-empty-then-populated ===
Intent: The same currency returns an empty answer for a range outside its data and a non-empty answer for a range covering it, so the empty case is range-driven.
Requires: executable=python3; scope=test
Requires: python-package=fastapi; scope=test
Requires: python-package=httpx2; scope=test

from app_server.testing import web_client from persistence.testing import db_session

code = "ZZG" date, rate = "1800-12-05", "4.25" route = "/history/{code}" with db_session() as db: db.rates.replace_rate(date=date, currency=code, rate=rate) client = web_client() empty = client.get(route.format(code=code), params={"start": "1800-12-06"}) assert empty.status_code == 200 assert empty.json()["count"] == 0 full = client.get(route.format(code=code), params={"start": date, "end": date}) assert full.status_code == 200 body = full.json() assert body["count"] == 1 assert body["points"] == [{"date": date, "rate": rate}] assert body["min"] == rate and body["max"] == rate === END AC history-empty-then-populated ===
