## Programmatic Acceptance

=== AC rates-upsert ===
Intent: A rate upsert can be read back with the exact values supplied by the criterion.

from persistence.testing import db_session

date_value = "2099-01-02"
currency_value = "ZZZ"
rate_value = "9.8765"

with db_session() as db:
    db.rates.upsert(date=date_value, currency=currency_value, rate=rate_value)
    rows = db.rates.list(date=date_value)
    assert any(row.date == date_value and row.currency == currency_value and row.rate == rate_value for row in rows)
=== END AC rates-upsert ===
