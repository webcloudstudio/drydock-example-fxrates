FEATURE: Effective-Date Rates

FieldValue
Version20261024 V1
DescriptionReturns stored rates for an effective publication date.
Depends OnFEATURE-API-FOUNDATION.md, DATABASE.md
ProvidesGET /rates/{date}, GET /rates/latest
Consumesrates repository operations

Purpose

Resolve a requested date to the latest ECB publication on or before that date. Return each stored currency rate as published text. A request before the first publication returns 404. The latest route identifies its request as latest.

Database Interface

  • FEATURE-DATA-003 — read: list rates for a publication - supplies: date - returns: date, currency, rate
  • FEATURE-DATA-006 — read: find the effective publication date - supplies: requested_date - returns: date

Routes

MethodPathBehavior
GET/rates/{date}Returns rates for the latest publication on or before the valid requested date.
GET/rates/latestReturns the latest publication and marks the request as latest.

Programmatic Acceptance

Requires: python-package=httpx; scope=test

=== AC rates-effective-date ===
Intent: The date route resolves a weekend-like request to the preceding stored publication and preserves the stored rate text.

from app_server.testing import web_client from persistence.testing import db_session

publication = "2099-05-01" requested = "2099-05-02" currency = "TST" rate = "1.2300" with db_session() as db: db.rates.upsert(date=publication, currency=currency, rate=rate) response = web_client().get(f"/rates/{requested}") assert response.status_code == 200 body = response.json() assert body["date"] == publication assert body["requested"] == requested assert body["rates"][currency] == rate === END AC rates-effective-date ===
