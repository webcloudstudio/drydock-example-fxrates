ARCHITECTURE: FxRates

FieldValue
Version20261024 V1
DescriptionDefines the application modules and boundaries for the FxRates service.
Providesapplication module boundaries

Technology Stack

  • Python 3.11 or newer provides the application language and runtime.
  • FastAPI provides the JSON API, served by uvicorn.
  • SQLite stores rates through the generated persistence package.
  • The root fxrates executable exposes the command line.
  • pytest and FastAPI TestClient support automated tests.

Modules

ModuleResponsibility
cliDispatches init, load, fetch, and serve commands.
app_serverCreates the FastAPI application and serves API routes.
persistenceProvides generated database operations from DATABASE.md.
servicesImplements loading, rate lookup, conversion, and history behavior using persistence.

Module Ownership

BoundaryOwnerAllowed access
ConfigurationconfigReads DATABASE_URL, then DATABASE_PATH, then data/app.db.
PersistencepersistenceOnly this generated package accesses the database driver and store.
File inputservicesReads a caller-supplied CSV or the extracted fetch file; does not read grader assets by application-specific paths.
External serviceservices.fetchDownloads the ECB archive; tests replace the download with a stub.
HTTPapp_serverCalls service functions and returns JSON/status responses.
CLIcliCalls service functions and maps outcomes to stdout, stderr, and exit codes.

Application modules must not import or open a database driver directly. Rates remain published text; arithmetic uses decimal.Decimal.

Programmatic Acceptance

Intent: The shared application packages import successfully.

User Acceptance

  • None.

Guardrails

  • Database access goes only through the generated persistence package.
  • Do not hardcode rates, dates, counts, or computed answers.
  • Application code never reads sources/run.sh or supplied data files by grader-specific paths.
