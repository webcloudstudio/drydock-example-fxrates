Planning Instructions

Delivery Shape

Build a Python command-line executable and a FastAPI JSON service over persistent SQLite-backed rates. The command flow initializes storage, validates and loads a complete ECB history file, and optionally fetches and loads the published history. The service reads that shared store to report health, statistics, available currencies, effective-date rates, conversions, and currency history. The supplied harness exercises the executable, loads staged CSV fixtures, starts the service locally, and verifies the combined behavior.

Test and Acceptance Strategy

Feature stories use focused pytest checks for their CLI or endpoint behavior. Tests use a real temporary database and stub the fetch download. The terminal verification story runs the complete supplied grader using sh sources/run.sh; its acceptance assertion declares Suite: full. Project-wide proof criteria are recorded in Sea Trials.

Sequencing and Dependencies

The database initialization and persistence boundary precede loading and database-backed API behavior. CSV validation and atomic load behavior precede fetch’s reuse of the loader. The API stories depend on storage access and effective-date resolution where applicable. Focused tests accompany implementation; the full supplied grader is the terminal verification gate and depends on every implementation story. Stage the grader’s three CSV inputs at the expected paths.
