Planning Instructions

Delivery Shape

A Python command-line executable provides initialization, CSV loading, fetching, and service startup. It writes ECB reference-rate history to the configured SQLite database through the shipped persistence layer. A FastAPI JSON service reads that shared data to provide health, statistics, currency listing, effective-date rates, conversions, and bounded history. The primary flow is initialize, load one or more ECB files, start the service, and query rates or derived answers. Fetch is a separate import path; the supplied grader does not invoke it.

Sequencing and Dependencies

Create the Python executable and persistence boundary before initialization and load. CSV validation must precede writes so rejected files leave storage unchanged. Initialization and valid loading precede data-backed endpoint work. API service startup depends on the persistence integration and FastAPI routes. Rates resolution supports conversion; stored rate reads support history. The full verification story follows every implementation story. The staged harness requires all three staged CSV fixtures.
