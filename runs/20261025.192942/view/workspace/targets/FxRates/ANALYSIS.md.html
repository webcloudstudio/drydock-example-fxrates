Planning Instructions

Delivery Shape

A Python command-line application maintains ECB exchange-rate history in SQLite and serves a FastAPI JSON API through uvicorn. The main flow initializes the store, loads a supplied ECB CSV or fetches and loads the ECB archive, starts the server, and answers health, statistics, currency-list, effective-date rates, conversion, and history requests. Rates remain published text in storage and are calculated with decimal arithmetic.

Test and Acceptance Strategy

Keep story verification bounded to the capability each story implements. Stub the archive download in automated tests so tests never use the network. Run the staged sources/run.sh once as the terminal verification of the complete supplied conformance harness; it covers command output, server health, API status and bodies, and visibility of data loaded while the server is running.

Sequencing and Dependencies

Implement the rates persistence boundary and CSV validation before loading and data-backed routes. Build command dispatch and initialization before load/fetch flows; fetch depends on the shared load path and archive extraction. Data-backed API routes depend on the repository read capabilities. Implement server operation and validation alongside route delivery. The full supplied harness is terminal and depends on all implementation stories.
