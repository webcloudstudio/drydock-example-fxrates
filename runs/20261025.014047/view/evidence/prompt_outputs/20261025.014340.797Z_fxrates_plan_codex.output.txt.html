# FEATURE: API Currency Conversion

| Field       | Value |
|-------------|-------|
| Version     | 20261025 V1 |
| Description | Converts amounts between currencies using effective ECB rates and exact decimal arithmetic. |
| Depends On  | ARCHITECTURE.md, DATABASE.md |
| Provides    | GET /convert |
| Consumes    | rates.get, rates.list |

## Questions

- None.

## Purpose

Allow callers to convert an amount from one currency to another, using the latest publication date on or before the requested date. If no date is supplied, use the latest publication date.

## Trigger and workflow

`GET /convert` requires `from`, `to`, and `amount` query parameters; `date` is optional. EUR has an implicit rate of one. For other currencies, resolve rates from the selected publication date. Return 404 if either requested non-EUR currency has no rate on that date.

Validate dates and amounts according to the API contract. Amounts must match `[0-9]+(\.[0-9]+)?`. Calculate with `decimal.Decimal`, using half-even rounding: return the conversion rate with six decimal places and the result with two decimal places. Calculate the result from the unrounded rate.

The JSON response contains `date`, `from`, `to`, `amount`, `rate`, and `result`. Echo the amount as supplied.

## Programmatic Acceptance

=== AC convert-request-contract ===
Intent: The conversion endpoint accepts a valid request and echoes its supplied date, currencies, and amount.

from app_server.testing import web_client
from persistence.testing import db_session

date = "2099-12-30"
source_currency = "ZZZ"
target_currency = "YYY"
source_rate = "2"
target_rate = "5"
amount = "12.50"

with db_session() as db:
    db.rates.upsert(date=date, currency=source_currency, rate=source_rate)
    db.rates.upsert(date=date, currency=target_currency, rate=target_rate)

client = web_client()
response = client.get(
    "/convert",
    params={
        "from": source_currency,
        "to": target_currency,
        "amount": amount,
        "date": date,
    },
)
assert response.status_code == 200
body = response.json()
assert body["date"] == date
assert body["from"] == source_currency
assert body["to"] == target_currency
assert body["amount"] == amount
assert isinstance(body["rate"], str)
assert isinstance(body["result"], str)
=== END AC convert-request-contract ===

## User Acceptance

- None.

## Guardrails

- Use `Decimal` for all rate and amount arithmetic; never use floating point.
- Round half to even, formatting the rate to six decimal places and the result to two.
- Compute the result from the exact rates, not from the rounded response rate.
- Return 422 for malformed dates or amounts and missing required parameters; return 404 for unavailable currencies or dates.

# FEATURE: Currency History

| Field       | Value |
|-------------|-------|
| Version     | 20261025 V1 |
| Description | Retrieves bounded currency publication history with exact summary statistics. |
| Depends On  | ARCHITECTURE.md, DATABASE.md |
| Provides    | GET /history/{code} |
| Consumes    | rates.list |

## Questions

- None.

## Purpose

Return a currency's ECB publication history, optionally bounded by inclusive `start` and `end` dates. Points are ordered by ascending publication date and retain the rate text stored in the database.

The response contains `currency`, `base`, `count`, `min`, `max`, `mean`, and `points`. Calculate minimum and maximum by numeric value while returning their stored rate text. Calculate the mean using `Decimal`, rounded half to even to six decimal places and formatted with exactly six decimals.

When the requested currency has stored rates but the selected bounds contain no points, return count zero, null statistics, and an empty points list. Return 404 when the currency has no stored rates at all, including EUR. Malformed date bounds return 422.

## Programmatic Acceptance

=== AC history-bounded-points ===
Intent: The history endpoint returns stored points in ascending date order and calculates summary fields from the supplied rates.

from decimal import Decimal, ROUND_HALF_EVEN
from app_server.testing import web_client
from persistence.testing import db_session

currency = "ZZZ"
first_date = "2099-12-30"
second_date = "2099-12-31"
first_rate = "1.2"
second_rate = "1.4"
mean = (
    (Decimal(first_rate) + Decimal(second_rate)) / Decimal(2)
).quantize(Decimal("0.000001"), rounding=ROUND_HALF_EVEN)
expected_mean = format(mean, ".6f")

with db_session() as db:
    db.rates.upsert(date=second_date, currency=currency, rate=second_rate)
    db.rates.upsert(date=first_date, currency=currency, rate=first_rate)

response = web_client().get(
    f"/history/{currency}",
    params={"start": first_date, "end": second_date},
)
assert response.status_code == 200
body = response.json()
assert body["currency"] == currency
assert body["base"] == "EUR"
assert body["count"] == 2
assert body["min"] == first_rate
assert body["max"] == second_rate
assert body["mean"] == expected_mean
assert body["points"] == [
    {"date": first_date, "rate": first_rate},
    {"date": second_date, "rate": second_rate},
]
=== END AC history-bounded-points ===

=== END AC history-empty-and-unknown ===

## User Acceptance

- None.

## Guardrails

- Include publication dates within the supplied bounds, inclusive, in ascending order.
- Preserve stored rate text in points and in minimum and maximum fields.
- Use exact decimal arithmetic and half-even rounding for the six-decimal mean.
- Return the specified empty bounded result for a currency with stored history; return 404 when that currency has no stored rates.
