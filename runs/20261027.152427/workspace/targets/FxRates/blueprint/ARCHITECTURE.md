## Overview

FxRates keeps the ECB euro reference rate history in one SQLite table and serves it two ways: the
`fxrates` executable (`init`, `load`, `fetch`, `serve`) and a FastAPI JSON API bound to
`127.0.0.1`. EUR is the base currency. Rates are stored as the ECB's published text, and all
arithmetic uses `decimal`, never floating point.

## Project Layout

| Path | Purpose |
|------|---------|
| `pyproject.toml`, `uv.lock` | Python 3.11+ project; dependencies fastapi, uvicorn, httpx2, pytest; committed lockfile. |
| `.venv` | Environment created by `uv venv`; launchers in `bin/` and `fxrates` activate it. |

| `cli/` | Command line foundation: `main`, dispatcher, usage validation, `testing.cli_runner`. |
| `app_server/` | Web foundation: `create_app`, module-level `app`, `testing.web_client`. |
| `persistence/` | Generated by Drydock from `DATABASE.md`; never hand-written. |
| `tests/` | pytest suite with `conftest.py`, written beside the code. |
| `sources/` | Read-only scoring assets; never read by application code. |

## Module Ownership

| Boundary | Owning module | Allowed low-level access |
|----------|---------------|--------------------------|
| Persistence | `persistence` (generated) | The only module that imports a database driver. |
| Configuration | `fxrates_app.config` | Reads `DATABASE_URL`, `DATABASE_PATH`; opens the store via `persistence.open_database`. |
| ECB parsing | `fxrates_app.ecb` | Pure functions over CSV text; no I/O to the store. |
| Network | `fxrates_app.fetch` | `download_archive(url)` is the only network call and the test seam. |
| Rate queries | `fxrates_app.rates`, `history`, `convert` | Call `db.rates.<operation>(...)` only. |
| Command line | `cli` | Dispatch, usage validation, exit codes; diagnostics to standard error. |
| HTTP | `app_server` | Application factory and shared router registry. |

Routes and commands call services; services call `db.rates.<operation>(...)`. SQL, table names, and
column names never cross the persistence boundary. Application code never imports `sqlite3` or any
other driver.

## Technology Stack

| Technology | Where it applies |
|------------|------------------|
| Python 3.11+ | Whole application. |
| FastAPI, uvicorn | JSON API served on `127.0.0.1`, default port 8000. |
| SQLite | The `rates` table, reached through the shipped persistence library. |
| CLI | The `fxrates` executable. |
| pytest, FastAPI `TestClient` | Test suite behind `bin/test.sh`. |
| ECB reference rates | Input: `eurofxref-hist.csv`, downloaded as `eurofxref-hist.zip`. |
| POSIX sh | `fxrates` launcher and `bin/test.sh`. |

## Technical Decisions

- Exit codes: `0` success, `1` operational failure, `2` usage error, `3` rejected file.
- Failing commands write nothing to standard output and one diagnostic line to standard error.
- Database location: `DATABASE_URL` (optional `sqlite://` prefix), then `DATABASE_PATH`, then `data/app.db`.
- Tests never open a network connection; `fetch` tests replace `fxrates_app.fetch.download_archive`.
- Diagnostics go to standard error and are never compared.

=== AC arch-no-driver-import ===
Intent: Application packages never import a database driver; only the generated persistence package may.

from pathlib import Path

banned = ("import sqlite3", "from sqlite3", "import psycopg", "from psycopg")
offenders = []
for pkg in ("fxrates_app", "cli", "app_server"):
    base = Path(pkg)
    if not base.is_dir():
        continue
    for path in base.rglob("*.py"):
        for line in path.read_text(encoding="utf-8").splitlines():
            if line.strip().startswith(banned):
                offenders.append(f"{path}: {line.strip()}")
print(offenders)
assert offenders == []
=== END AC arch-no-driver-import ===

## Guardrails

- Do not modify, rewrite, regenerate, or substitute any file under `sources/`.
- Application code never reads `sources/run.sh` or any supplied data file; data reaches the database only through `fxrates load` or `fxrates fetch`.
- Do not hardcode a rate, a date, a count, or a computed value; every value comes from a query.
- Do not open a database driver outside the shipped persistence library.
- Compute with `decimal`, never with floating point.
