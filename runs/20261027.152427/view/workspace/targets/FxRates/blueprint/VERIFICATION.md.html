Purpose

Assembly and intent only. Every behavior is implemented by earlier stories. This story runs the supplied grader sources/run.sh, unmodified and unfiltered, from the application root. The script's exit status is the verdict: it loads the supplied ECB files, starts fxrates serve on a free local port, and makes 35 checks of command output and HTTP status and JSON body.

Behavior

  • The grader and its data files under sources/ are read-only scoring assets and are never

modified, regenerated, or substituted.

  • Application code never reads sources/run.sh or the supplied data files.
  • A nonzero exit means a check failed; the printed FAIL lines identify it.
