FEATURE: Load Store

FieldValue
Version20261027 V1
Descriptionfxrates load <csv> validates an ECB history file, stores its rates as text in one transaction, and reports the dates and rates counts.
Depends OnFEATURE-LoadValidation.md, FEATURE-InitCommand.md, DATABASE.md
Providesfxrates load
Consumesfxrates_app.ecb.parse_history, rates.replace_rate, fxrates_app.config.database_path, cli.main

Purpose

fxrates load <csv> reads an ECB history file, validates it completely with fxrates_app.ecb.parse_history, and then upserts every non-N/A rate through rates.replace_rate in a single transaction, so a reader sees all or none of the load.

Behavior

  • A rejected file (RejectedFile) exits 3, prints nothing to standard output, writes one

diagnostic line to standard error, and stores nothing.

  • On success it prints dates,rates on the first line and <dates>,<rates> on the second, where

dates counts the dates in the file with at least one stored rate and rates counts the rates stored.

  • A rate for a (date, currency) already stored replaces it, so loading the same file twice leaves the

database unchanged.

  • A file holding only N/A values prints 0,0 and stores nothing.
  • Unreadable files are handled by FEATURE-LoadUnreadable.md.

Database Interface

  • FEATURE-RATE-001 — write: store a rate, replacing the stored one - supplies: date, currency, rate - returns: date, currency, rate

=== AC load-counts-and-text ===
Intent: A valid file exits 0, reports the dates and rates counts derived from the fixture (an all-N/A date is not counted), and stores each rate as published text.
Requires: executable=python3; scope=test

import csv import os import tempfile from persistence.testing import db_session from cli.testing import cli_runner

header = ["Date", "ZZA", "ZZB", "ZZH"] rows = [ ["1900-08-03", "1.50", "N/A", "N/A"], ["1900-08-02", "0.943", "2", "N/A"], ["1900-08-01", "N/A", "N/A", "N/A"], ] stored = [(r[0], c, v) for r in rows for c, v in zip(header[1:], r[1:]) if v != "N/A"] n_dates = len({d for d, _, _ in stored}) n_rates = len(stored)

with db_session() as db: with tempfile.TemporaryDirectory() as tmp: path = os.path.join(tmp, "in.csv") with open(path, "w", newline="") as fh: w = csv.writer(fh, lineterminator="\n") w.writerow(header + [""]) for r in rows: w.writerow(r + [""]) code, out, err = cli_runner("load", path) assert code == 0 lines = out.splitlines() assert lines[0] == "dates,rates" got_dates, got_rates = lines[1].split(",") assert int(got_dates) == n_dates assert int(got_rates) == n_rates assert len(lines) == 2 for cur in header[1:]: hist = db.rates.list_currency_history(currency=cur) assert [(r.date, r.rate) for r in hist] == sorted((d, v) for d, c, v in stored if c == cur) assert db.rates.list_for_date(date="1900-08-01") == [] === END AC load-counts-and-text ===

import csv from persistence.testing import db_session from cli.testing import cli_runner

path = "sources/eurofxref-hist_2025-01.csv" with open(path, newline="") as fh: table = list(csv.reader(fh)) codes = [h for h in table[0][1:] if h] cells = [] for row in table[1:]: for code, value in zip(codes, row[1:1 + len(codes)]): if value != "N/A": cells.append((row[0], code, value)) n_dates = len({d for d, _, _ in cells}) n_rates = len(cells)

User Acceptance

  • None.

Guardrails

  • A rejected file changes nothing: the whole file is validated before the first write.
  • The load is applied in one transaction so a reader never sees a partly applied load.
  • Rates are stored as published text and arithmetic never uses floating point.
  • Standard output carries only the counts; failures write one diagnostic line to standard error.
