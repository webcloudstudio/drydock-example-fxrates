FEATURE: Init Command

FieldValue
Version20261027 V1
Descriptionfxrates init empties the rates table, prints nothing, and exits 0.
Depends OnFEATURE-CliUsageErrors.md, FEATURE-DatabaseSelection.md, DATABASE.md
Providesfxrates init
Consumescli.main, fxrates_app.config.database_path, rates.delete_from_date

Purpose

fxrates init resets the rates store to empty. The schema is provisioned by the DATABASE step and application code never runs DDL or opens a driver, so init removes every stored rate through the declared rates.delete_from_date operation, passing a from_date earlier than any publication (0000-01-01). Afterward the table exists and holds no rows.

Behavior

  • Registers the init handler with the dispatcher in cli.
  • Opens the store through persistence.open_database using the configured database location.
  • Removes every row, prints nothing to standard output, and exits 0.
  • Init takes no arguments; a wrong argument count is a usage error owned by FEATURE-CliUsageErrors.md.
  • Running init on an already empty store succeeds and changes nothing.

Database Interface

  • FEATURE-RATE-007 — write: remove every stored rate - supplies: from_date - returns: —

=== AC init-idempotent ===
Intent: Running init twice in a row exits 0 both times, prints nothing, and leaves the store empty.
