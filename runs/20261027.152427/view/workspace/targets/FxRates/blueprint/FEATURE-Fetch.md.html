FieldValue

Purpose

fxrates fetch obtains the ECB euro reference rate history without a file argument. It downloads https://www.ecb.europa.eu/stats/eurofxref/eurofxref-hist.zip, extracts the member eurofxref-hist.csv, and loads that text exactly as fxrates load does.

Trigger

The command line: ./fxrates fetch. It takes no arguments; a wrong argument count is a usage error (exit 2) handled by the shared validation.

Sequence

  1. Call fxrates_app.fetch.download_archive(url) for the ECB URL. It returns the archive bytes and

uses urllib with a builder-chosen timeout. It is the only function in the application that opens a network connection.

  1. The handler must call it through the module attribute (fxrates_app.fetch.download_archive(...)),

never through a name imported into another module, so tests replace the single seam.

  1. Open the bytes as a zip archive and read the member eurofxref-hist.csv.
  2. Pass its text through the same parse, validate, and transactional store path used by load

(fxrates_app.ecb.parse_history, then one transaction of upserts).

  1. Print dates,rates then <dates>,<rates>, as load does, and exit 0.

Intent: With the download stubbed to return a zip holding the CSV, fetch exits 0, reports the date and rate counts, and stores each published rate text exactly.
Requires: executable=python3; scope=test

import csv import io import zipfile from unittest import mock

from cli.testing import cli_runner from persistence.testing import db_session

d = "1900-08-01" ra = "1.50" rb = "2.250"

buf = io.StringIO() w = csv.writer(buf, lineterminator="\n") w.writerow(["Date", "ZZA", "ZZB", ""]) w.writerow([d, ra, rb, ""]) text = buf.getvalue()

bio = io.BytesIO() with zipfile.ZipFile(bio, "w") as z: z.writestr("eurofxref-hist.csv", text) data = bio.getvalue()

with db_session() as db: with mock.patch("fxrates_app.fetch.download_archive", return_value=data): code, out, err = cli_runner("fetch") print(out) print(err) assert code == 0 lines = out.splitlines() assert lines[0] == "dates,rates" assert lines[1].split(",") == [str(1), str(2)] rows = {r.currency: r.rate for r in db.rates.list_for_date(date=d)} assert rows["ZZA"] == ra assert rows["ZZB"] == rb === END AC fetch-loads-archive ===

Guardrails

  • No test opens a network connection; the download is replaced at fxrates_app.fetch.download_archive.
  • A failing command writes nothing to standard output and one diagnostic line to standard error.
  • Rates are stored as the ECB's published text and never as floating point.
  • The timeout is builder-chosen because the sources state none.
