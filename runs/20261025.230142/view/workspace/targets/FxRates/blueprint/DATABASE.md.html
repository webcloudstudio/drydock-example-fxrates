Programmatic Acceptance

=== AC rates_get_round_trip ===
Intent: Retrieve a stored rate by its date and currency through the declared repository operation.

from persistence.testing import db_session

date = "2099-01-02" currency = "ZZZ" rate = "1.2300"

with db_session() as db: db.rates.upsert(date=date, currency=currency, rate=rate) row = db.rates.get(date=date, currency=currency)

assert row.date == date assert row.currency == currency assert row.rate == rate === END AC rates_get_round_trip ===

=== AC rates_list_filters_and_order ===
Intent: List stored rates in date and currency order and filter by currency and inclusive date bounds.

from persistence.testing import db_session

currency = "ZZZ" other_currency = "YYY" dates = ["2099-01-03", "2099-01-01", "2099-01-02"] rates = ["3.00", "1.00", "2.00"]

with db_session() as db: for date, rate in zip(dates, rates): db.rates.upsert(date=date, currency=currency, rate=rate) db.rates.upsert(date=dates[1], currency=other_currency, rate="8.00")

all_rows = db.rates.list() filtered = db.rates.list( currency=currency, start_date=dates[1], end_date=dates[2], )

assert [(row.date, row.currency, row.rate) for row in all_rows if row.date in dates] == [ ("2099-01-01", currency, "1.00"), ("2099-01-01", other_currency, "8.00"), ("2099-01-02", currency, "2.00"), ("2099-01-03", currency, "3.00"), ] assert [(row.date, row.currency, row.rate) for row in filtered] == [ (dates[1], currency, rates[1]), (dates[2], currency, rates[2]), ] === END AC rates_list_filters_and_order ===

=== AC rates_upsert_replaces ===

=== AC rates_delete_round_trip ===
Intent: Delete removes the selected date and currency rate from the repository.

from persistence.testing import db_session

date = "2099-03-01" currency = "ZZZ" rate = "4.50"

with db_session() as db: db.rates.upsert(date=date, currency=currency, rate=rate) deleted = db.rates.delete(date=date, currency=currency) row = db.rates.get(date=date, currency=currency)

Guardrails

  • Store each ECB rate exactly as published, using text and never floating point.
  • Reject an invalid input file before the first write; a rejected file changes nothing.
  • Replace an existing rate with the same date and currency.
  • Resolve the store from DATABASE_URL, then DATABASE_PATH, then data/app.db.
  • Application code accesses SQLite only through the generated persistence package.
  • Do not modify or read sources/run.sh or supplied data files from application code.
