Trigger and Behavior

fxrates load <csv> validates the entire CSV before its first write. The header begins with Date, followed by three-letter uppercase currency codes; a trailing empty field is ignored. Each data row has a real, non-repeated YYYY-MM-DD date and one value per currency. N/A is skipped; each other value must match [0-9]+(\.[0-9]+)? and be nonzero. Valid values are stored exactly as published text. Existing date/currency pairs are replaced.

On success, standard output is CSV with header dates,rates and one row containing the number of dates with at least one stored rate and the number of rates stored. An unreadable file exits 1; an invalid file exits 3. A failing command writes nothing to standard output and one diagnostic line to standard error.
