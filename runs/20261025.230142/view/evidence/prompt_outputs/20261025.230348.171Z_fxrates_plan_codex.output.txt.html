# FEATURE: Fetch ECB History

| Field | Value |
|-------|-------|
| Version | 20261025 V1 |
| Description | Fetch and load the ECB reference-rate history archive. |
| Depends On | FEATURE-CliFoundation.md, FEATURE-LoadHistory.md |
| Provides | `fxrates fetch` |
| Consumes | `fxrates load` |

## Questions

- None.

## Purpose

`fxrates fetch` downloads the ECB history ZIP, extracts `eurofxref-hist.csv`, and loads it using the same validation, replacement, reporting, and exit-code behavior as `fxrates load`.

## Workflow

Use Python standard-library download and ZIP facilities. Keep the download replaceable so automated tests can provide archive bytes without network access. Pass the extracted CSV through the shared loader; do not implement a separate parser or persistence path.

A failed download returns exit code `1`, writes no standard output, and emits one diagnostic line to standard error. A successfully fetched file follows the loader’s behavior.

## Programmatic Acceptance

import zipfile
from cli.testing import cli_runner

assert code in (0, 1)
=== END AC fetch_entry_point ===

=== AC fetch_loads_stubbed_archive ===
Intent: Fetch loads a valid ECB archive supplied by a stub without opening a network connection.

import io
import zipfile
from unittest.mock import patch
from cli.testing import cli_runner

csv_data = (
    "Date,ZZZ,\n"
    "2099-01-02,1.2300,\n"
).encode("ascii")
archive = io.BytesIO()
with zipfile.ZipFile(archive, "w") as bundle:
    bundle.writestr("eurofxref-hist.csv", csv_data)
payload = archive.getvalue()

with patch("urllib.request.urlopen") as download:
    download.return_value.__enter__.return_value.read.return_value = payload
    code, stdout, stderr = cli_runner("fetch")

assert code == 0
=== END AC fetch_loads_stubbed_archive ===

- Reuse the shared loader and its validation and reporting behavior.
- Automated tests replace the download with a stub and never use the network.
- Do not read or modify supplied files under `sources/`.

## Purpose

Provide JSON health, store statistics, and the sorted currency list from persisted rates.

## Routes

- `GET /health` returns status 200 and `{"status":"ok"}`.
- `GET /stats` returns publication-date and rate counts, plus first and last dates; both dates are null for an empty store.
- `GET /currencies` returns base EUR and every currency with a stored rate, in ascending order.

# FEATURE: Currency Conversion

| Field | Value |
|-------|-------|
| Version | 20261025 V1 |
| Description | Convert amounts between currencies using effective ECB rates. |
| Depends On | FEATURE-ApiFoundation.md, DATABASE.md |
| Provides | GET /convert |
| Consumes | rates repository operations |

## Questions

- None.

## Purpose

`GET /convert` accepts required `from`, `to`, and `amount` parameters and an optional date. Without a date it uses the latest publication. EUR has the implicit rate one. Return the effective date, input currencies, amount text, conversion rate, and result.

Compute with `decimal.Decimal`. The conversion rate is `rate(to) / rate(from)`, rounded half to even to six decimal places and formatted with six decimals. The result is computed from the unrounded rates and amount, rounded half to even to two decimal places and formatted with two decimals.

## Database Interface

- `FEATURE-RATE-002` — read: list rates - supplies: `currency`, `start_date`, `end_date` - returns: `date`, `currency`, `rate`

## Programmatic Acceptance

=== AC conversion_route ===
Intent: Conversion returns the supplied amount and currencies and a result derived from the stored rates.
Requires: python-package=httpx; scope=test

from decimal import Decimal, ROUND_HALF_EVEN
from persistence.testing import db_session
from app_server.testing import web_client

date = "2099-01-02"
source = "ZZZ"
target = "YYY"
source_rate = "2.00"
target_rate = "5.00"
amount = "2.00"
with db_session() as db:
    db.rates.upsert(date=date, currency=source, rate=source_rate)
    db.rates.upsert(date=date, currency=target, rate=target_rate)

response = web_client().get(
    "/convert",
    params={"from": source, "to": target, "amount": amount, "date": date},
)
assert response.status_code == 200
body = response.json()
expected_rate = (Decimal(target_rate) / Decimal(source_rate)).quantize(
    Decimal("0.000001"), rounding=ROUND_HALF_EVEN
)
expected_result = (Decimal(amount) * Decimal(target_rate) / Decimal(source_rate)).quantize(
    Decimal("0.01"), rounding=ROUND_HALF_EVEN
)
assert body["date"] == date
assert body["from"] == source
assert body["to"] == target
assert body["amount"] == amount
assert body["rate"] == f"{expected_rate:.6f}"
assert body["result"] == f"{expected_result:.2f}"
=== END AC conversion_route ===

# FEATURE: Currency History

| Field | Value |
|-------|-------|
| Version | 20261025 V1 |
| Description | Retrieve ordered currency history and statistics over optional date bounds. |
| Depends On | FEATURE-ApiFoundation.md, DATABASE.md |
| Provides | GET /history/{code} |
| Consumes | rates repository operations |

## Questions

- None.

## Purpose

Return a currency’s stored publication points in ascending date order, optionally filtered by inclusive `start` and `end` bounds. Include count, minimum and maximum by numeric rate value, and the exact arithmetic mean rounded half to even to six decimal places and formatted with six decimals. Preserve rate text for points and extrema. When there are no points, return count zero and null statistics with an empty points list. A currency with no stored rate at all returns 404.

## Database Interface

- `FEATURE-RATE-002` — read: list rates - supplies: `currency`, `start_date`, `end_date` - returns: `date`, `currency`, `rate`

## Programmatic Acceptance

=== AC history_points_and_mean ===
Intent: History returns stored points in date order and computes count and mean from their exact decimal values.
Requires: python-package=httpx; scope=test

from decimal import Decimal, ROUND_HALF_EVEN
from persistence.testing import db_session
from app_server.testing import web_client

currency = "ZZZ"
dates = ["2099-01-03", "2099-01-01", "2099-01-02"]
rates = ["3.00", "1.00", "2.00"]
with db_session() as db:
    for date, rate in zip(dates, rates):
        db.rates.upsert(date=date, currency=currency, rate=rate)

response = web_client().get(f"/history/{currency}")
assert response.status_code == 200
body = response.json()
expected_dates = sorted(dates)
expected_mean = (sum(map(Decimal, rates)) / Decimal(len(rates))).quantize(
    Decimal("0.000001"), rounding=ROUND_HALF_EVEN
)
assert [point["date"] for point in body["points"]] == expected_dates
assert [point["rate"] for point in body["points"]] == [
    rates[dates.index(date)] for date in expected_dates
]
assert body["currency"] == currency
assert body["count"] == len(rates)
assert body["mean"] == f"{expected_mean:.6f}"
=== END AC history_points_and_mean ===
