FEATURE: Service Overview

FieldValue
Version20261026 V1
DescriptionServes health, database statistics, and available currencies.
Depends OnARCHITECTURE.md, DATABASE.md
ProvidesGET /health, GET /stats, GET /currencies

Purpose

Expose basic service health and a summary of the rates currently stored.

Routes

Method and pathBehavior
GET /healthAlways returns status 200 and {"status":"ok"}.
GET /statsReturns distinct publication-date count, stored-rate count, and earliest/latest publication dates. Empty date bounds are null.
GET /currenciesReturns base EUR and the ascending codes with at least one stored rate.

Database Interface

  • FEATURE-RATE-005 — read: list all stored rates - supplies: — - returns: date, currency, rate

Programmatic Acceptance

=== AC overview-routes ===
Intent: Health, statistics, and currencies routes are reachable and reflect persisted state.

Requires: python-package=httpx; scope=test

from app_server.testing import web_client from persistence.testing import db_session

with db_session() as db: date = "2096-08-01" rate = "1.75" db.rates.upsert(date=date, currency="ZZZ", rate=rate)

client = web_client() health = client.get("/health") stats = client.get("/stats") currencies = client.get("/currencies") assert health.status_code == 200 assert health.json()["status"] == "ok" assert stats.status_code == 200 assert stats.json()["dates"] >= 1 assert stats.json()["rates"] >= 1 assert stats.json()["first"] is not None assert stats.json()["last"] is not None assert currencies.status_code == 200 assert "ZZZ" in currencies.json()["currencies"] === END AC overview-routes ===
