<requirement name="fresh-database-cli-init" stories="data-001">
Runs ./fxrates against a fresh database: loads the supplied ECB files from the command line,
</requirement>
<requirement name="cli-command-exit-and-output" stories="data-001,data-002">
compares every command's exit code and standard output,
</requirement>
<requirement name="http-response-status-and-json" stories="api-001,api-002,api-003,api-004">
and every HTTP response's status and JSON body, with the known answer below.
</requirement>
<requirement name="json-value-comparison" stories="qa-002">
JSON bodies are compared as values, so key order and whitespace do not matter.
</requirement>
<requirement name="offline-grading" stories="qa-002">
No network beyond 127.0.0.1 is used.
</requirement>
<requirement name="executable-deliverable" stories="qa-002">
The deliverable is an executable named fxrates at the application root.
</requirement>
<requirement name="exit-on-all-checks-pass" stories="qa-002">
Exit 0 only when every check passes.
</requirement>
