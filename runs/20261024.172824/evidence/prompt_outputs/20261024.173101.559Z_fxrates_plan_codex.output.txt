# FEATURE: Effective Date Rates

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Retrieves stored exchange rates for a requested or latest effective publication date. |
| Depends On  | ARCHITECTURE.md, DATABASE.md |
| Provides    | GET /rates/{date}, GET /rates/latest |
| Consumes    | rates.list |

## Questions

- None.

## Purpose

Return all rates stored for the latest publication on or before the requested date. EUR is the base and has an implicit rate of 1; only currencies with stored rates appear in the response.

## Workflow

- `GET /rates/{date}` accepts a real calendar date in `YYYY-MM-DD` form. It returns the effective publication date, the original requested date, base `EUR`, and the rates for that publication.
- `GET /rates/latest` returns the latest publication and uses `"latest"` as the requested value.
- Return 404 when no publication exists on or before the requested date. Return 422 for a malformed date.

## Database Interface

- `FEATURE-RATE-002` — read: list rates for a publication date - supplies: `date` - returns: `date`, `currency`, `rate`

## Programmatic Acceptance

=== AC rates-effective-date ===
Intent: The date endpoint resolves a seeded date to the latest available publication and returns its stored rate text.

from app_server.testing import web_client
from persistence.testing import db_session

requested = "2001-01-03"
currency = "USD"
rate = "1.2345"

    db.rates.upsert(date=date, currency=currency, rate=rate)

body = response.json()
assert response.status_code == 200
assert body["date"] == date
assert body["requested"] == requested
assert body["base"] == "EUR"

- None.

# FEATURE: Currency Conversion

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Converts an amount between currencies using rates from an effective publication date. |
| Depends On  | ARCHITECTURE.md, DATABASE.md |
| Provides    | GET /convert |
| Consumes    | rates.list |

## Questions

- None.

## Purpose

Convert between any two currencies using EUR as the base. If no date is supplied, use the latest publication. If a date is supplied, resolve it to the latest publication on or before that date.

## Workflow

Require `from`, `to`, and `amount`. Amount must match `[0-9]+(\.[0-9]+)?` and is echoed as supplied. EUR has an implicit rate of 1. Compute `rate(to) / rate(from)` exactly and round half to even to six decimal places. Compute `amount × rate(to) / rate(from)` from the unrounded rates and round half to even to two decimal places. Return both as strings with exactly six and two decimal places respectively.

Return 404 if there is no effective publication or a non-EUR currency has no rate for it. Return 422 for a malformed amount or date, or a missing required parameter.

## Database Interface

- `FEATURE-RATE-002` — read: list rates for a publication date - supplies: `date` - returns: `date`, `currency`, `rate`

## Programmatic Acceptance

=== AC convert-exact-values ===
Intent: Conversion returns the supplied amount and the exact same-currency ratio with contract precision.

from persistence.testing import db_session

currency = "USD"
rate = "1.25"
amount = "2.50"

with db_session() as db:
    db.rates.upsert(date=date, currency=currency, rate=rate)

response = web_client().get(
    "/convert",
    params={"from": currency, "to": currency, "amount": amount, "date": date},
)
body = response.json()
assert response.status_code == 200
assert body["date"] == date

## Guardrails

- Reach persistence only through the declared persistence library.

# FEATURE: Currency History

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Returns a currency's stored publication history and exact summary statistics. |
| Depends On  | ARCHITECTURE.md, DATABASE.md |
| Provides    | GET /history/{code} |
| Consumes    | rates.list |

## Questions

- None.

## Purpose

Return the stored rates for a currency in ascending publication-date order, with optional inclusive `start` and `end` date bounds. Report count, minimum, maximum, and exact mean. The minimum and maximum are the stored text for the values selected by numeric value. The mean is rounded half to even to six decimal places and returned as a string with exactly six decimal places.

If the range has no points, return count zero, null statistics, and an empty points list. Return 404 if the currency has no stored rate at all, including EUR. Malformed date bounds return 422.

## Database Interface

- `FEATURE-RATE-002` — read: list rates for a publication date - supplies: `date` - returns: `date`, `currency`, `rate`

## Programmatic Acceptance

=== AC history-bounded-points ===
Intent: History returns stored points within inclusive date bounds, in ascending order, with summary values.

from app_server.testing import web_client
from persistence.testing import db_session

currency = "USD"
first_date = "2001-01-10"
second_date = "2001-01-11"
first_rate = "1"
second_rate = "3"

with db_session() as db:
    db.rates.upsert(date=first_date, currency=currency, rate=first_rate)
    db.rates.upsert(date=second_date, currency=currency, rate=second_rate)

response = web_client().get(
    f"/history/{currency}",
    params={"start": first_date, "end": second_date},
)
body = response.json()
assert response.status_code == 200
assert body["currency"] == currency
assert body["base"] == "EUR"
assert body["count"] == 2
assert body["min"] == first_rate
assert body["max"] == second_rate
assert body["points"] == [
    {"date": first_date, "rate": first_rate},
    {"date": second_date, "rate": second_rate},
]
=== END AC history-bounded-points ===

=== AC history-empty-range ===
Intent: An empty bounded history range returns empty points and null statistics.

=== AC history-unknown-currency ===

=== END AC history-unknown-currency ===

=== AC history-malformed-bound ===
Intent: A malformed history date bound returns 422.

=== END AC history-malformed-bound ===

## User Acceptance

- None.

## Guardrails

- Preserve stored rate text in point, minimum, and maximum values.
- Calculate the mean with exact decimal arithmetic and half-to-even rounding.
- Apply date bounds inclusively and return points in ascending date order.
- Reach persistence only through the declared persistence library.
