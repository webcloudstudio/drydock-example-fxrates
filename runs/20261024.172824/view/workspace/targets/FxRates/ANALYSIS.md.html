Planning Instructions

Delivery Shape

Build an executable CLI and a FastAPI JSON service backed by SQLite. The CLI initializes the store and loads ECB CSV data; the API reads the resulting rates to answer health, statistics, currency, date-rate, conversion, and history requests. The main flow is initialize, load data, serve requests, then run the supplied grader.

Test and Acceptance Strategy

Use focused tests for command behavior, CSV validation and atomicity, route responses, effective-date resolution, and exact decimal rounding. Stub fetch downloads in tests so tests do not open network connections. The terminal verification story runs the complete supplied grader once as the project conformance gate. Sea Trials separately records the supplied grader as the acceptance proof.

Sequencing and Dependencies

Implement the persistence boundary and initialization before loading and API reads. Complete CSV validation before writes; build fetch on the load capability. Implement API routes and service startup before terminal verification. Stage the supplied harness and all three CSV fixtures before its run. The terminal verification story depends on all implementation stories.
