FEATURE: Currency History

FieldValue
Version20261024 V1
DescriptionReturns a currency's stored publication history and exact summary statistics.
Depends OnARCHITECTURE.md, DATABASE.md
ProvidesGET /history/{code}
Consumesrates.list

Purpose

Return the stored rates for a currency in ascending publication-date order, with optional inclusive start and end date bounds. Report count, minimum, maximum, and exact mean. The minimum and maximum are the stored text for the values selected by numeric value. The mean is rounded half to even to six decimal places and returned as a string with exactly six decimal places.

If the range has no points, return count zero, null statistics, and an empty points list. Return 404 if the currency has no stored rate at all, including EUR. Malformed date bounds return 422.

Database Interface

  • FEATURE-RATE-002 — read: list rates for a publication date - supplies: date - returns: date, currency, rate

Programmatic Acceptance

=== AC history-bounded-points ===
Intent: History returns stored points within inclusive date bounds, in ascending order, with summary values.

from app_server.testing import web_client from persistence.testing import db_session

currency = "USD" first_date = "2001-01-10" second_date = "2001-01-11" first_rate = "1" second_rate = "3"

with db_session() as db: db.rates.upsert(date=first_date, currency=currency, rate=first_rate) db.rates.upsert(date=second_date, currency=currency, rate=second_rate)

response = web_client().get( f"/history/{currency}", params={"start": first_date, "end": second_date}, ) body = response.json() assert response.status_code == 200 assert body["currency"] == currency assert body["base"] == "EUR" assert body["count"] == 2 assert body["min"] == first_rate assert body["max"] == second_rate assert body["points"] == [ {"date": first_date, "rate": first_rate}, {"date": second_date, "rate": second_rate}, ] === END AC history-bounded-points ===
