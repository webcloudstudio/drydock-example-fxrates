Programmatic Acceptance

=== AC rates-get-round-trip ===
Intent: A rate can be retrieved by its date and currency key.

from persistence.testing import db_session

date = "2001-01-02" currency = "USD" rate = "1.2345"

with db_session() as db: db.rates.upsert(date=date, currency=currency, rate=rate) observed = db.rates.get(date=date, currency=currency) assert observed is not None assert observed.date == date assert observed.currency == currency assert observed.rate == rate === END AC rates-get-round-trip ===

=== AC rates-list-date ===
Intent: Listing rates filters by publication date and returns currency order.

from persistence.testing import db_session

date = "2001-01-03" usd = "1.1" jpy = "120"

with db_session() as db: db.rates.upsert(date=date, currency="USD", rate=usd) db.rates.upsert(date=date, currency="JPY", rate=jpy) rows = db.rates.list(date=date) assert [(row.currency, row.rate) for row in rows] == [("JPY", jpy), ("USD", usd)] === END AC rates-list-date ===

=== AC rates-upsert-replaces ===
Intent: Upserting the same date and currency replaces its stored text.

from persistence.testing import db_session

date = "2001-01-04" currency = "GBP" original = "0.83" replacement = "0.8300"

with db_session() as db: db.rates.upsert(date=date, currency=currency, rate=original) db.rates.upsert(date=date, currency=currency, rate=replacement) observed = db.rates.get(date=date, currency=currency) assert observed is not None assert observed.rate == replacement === END AC rates-upsert-replaces ===

=== AC rates-delete-round-trip ===
Intent: Deleting a rate by date and currency removes that stored row.

from persistence.testing import db_session

date = "2001-01-05" currency = "CAD"

with db_session() as db: db.rates.upsert(date=date, currency=currency, rate="1.4") db.rates.delete(date=date, currency=currency) assert db.rates.get(date=date, currency=currency) is None === END AC rates-delete-round-trip ===

Guardrails

  • Rates remain stored as text exactly as published.
  • All rate arithmetic uses decimal and never floating point.
  • Application code accesses SQLite only through the generated persistence library.
  • Never assume the database is empty or reset it from acceptance criteria.
