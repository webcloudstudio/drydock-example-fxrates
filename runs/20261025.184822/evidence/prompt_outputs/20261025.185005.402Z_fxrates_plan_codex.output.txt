=== AC rate-list-round-trip ===
Intent: The rates list operation returns the rows created through the generated persistence interface.

from persistence.testing import db_session

with db_session() as db:
    marker = "2099-01-01"
    db.rates.replace_rate(date=marker, currency="USD", rate="1.234")
    rows = db.rates.list()
    assert any(row.date == marker and row.currency == "USD" and row.rate == "1.234" for row in rows)

=== AC rate-upsert-round-trip ===

## Guardrails

- Rate values remain the ECB's published text.
- The unique key is the publication date and currency pair.
- Application code accesses storage only through the generated persistence package.
- Application arithmetic uses `decimal`; rates are never represented as floating-point values.
