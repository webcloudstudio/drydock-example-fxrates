## Programmatic Acceptance

=== AC rates-upsert-roundtrip ===
Intent: The declared upsert operation stores and replaces a rate, and a separate get reads it back.

from persistence.testing import db_session

date = "2099-01-02"
currency = "ZZZ"
rate = "1.2345"
replacement = "1.23450"

with db_session() as db:
    first = db.rates.upsert(date=date, currency=currency, rate=rate)
    assert first.date == date
    assert first.currency == currency
    assert first.rate == rate

    replaced = db.rates.upsert(date=date, currency=currency, rate=replacement)
    assert replaced.rate == replacement

    stored = db.rates.get(date=date, currency=currency)
    assert stored is not None
    assert stored.date == date
    assert stored.currency == currency
    assert stored.rate == replacement
=== END AC rates-upsert-roundtrip ===

=== AC rates-list ===
Intent: The declared list operation returns rows with the declared rate fields.

from persistence.testing import db_session

with db_session() as db:
    rows = db.rates.list()

## Guardrails

- Preserve every published rate as text; never store or compute rates as floating-point values.
- Validate the complete history file before the first write.
- Do not modify or read the supplied scoring harness from application code.
