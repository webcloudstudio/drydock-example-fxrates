## Programmatic Acceptance

=== AC rates-get-round-trip ===
Intent: The rates.get operation returns the row created by the declared upsert operation.

from persistence.testing import db_session

with db_session() as db:
    stored = db.rates.upsert(date="2001-01-01", currency="TST", rate="1.25")
    assert stored is not None
    found = db.rates.get(date="2001-01-01", currency="TST")
    assert found is not None
    assert found.date == stored.date
    assert found.currency == stored.currency
    assert found.rate == stored.rate
=== END AC rates-get-round-trip ===

=== AC rates-upsert-replaces ===
Intent: Repeating the rates.upsert operation replaces the stored rate for the same natural key.

from persistence.testing import db_session

with db_session() as db:
    first = db.rates.upsert(date="2001-01-01", currency="TST", rate="1.25")
    second = db.rates.upsert(date="2001-01-01", currency="TST", rate="1.30")
    found = db.rates.get(date="2001-01-01", currency="TST")
    assert found is not None
    assert found.rate == second.rate
    assert found.date == first.date
    assert found.currency == first.currency
=== END AC rates-upsert-replaces ===

=== AC rates-delete-round-trip ===
Intent: The rates.delete operation removes only the row identified by its date and currency.

from persistence.testing import db_session

with db_session() as db:
    row = db.rates.upsert(date="2001-01-01", currency="TST", rate="1.25")
    removed = db.rates.delete(date="2001-01-01", currency="TST")
    assert removed is not None
    assert removed.date == row.date
    assert removed.currency == row.currency
    assert db.rates.get(date="2001-01-01", currency="TST") is None
=== END AC rates-delete-round-trip ===

## Guardrails

- Rates are stored as ECB-published text and are never stored or returned as floating-point values.
- The date and currency pair uniquely identifies a publication rate.
- Application code does not open a database driver directly; it uses the generated persistence package.
