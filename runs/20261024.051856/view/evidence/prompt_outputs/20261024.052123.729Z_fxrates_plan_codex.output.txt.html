# FEATURE: Reject History

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Reject invalid ECB history files without changing stored rates. |
| Depends On  | FEATURE-Load-History.md, DATABASE.md |
| Provides    | atomic invalid-file rejection |
| Consumes    | fxrates load, rates repository operations |

## Questions

- None.

## Purpose

A malformed history file must be rejected as a whole. The loader validates every row before its first write, so a valid earlier row in the same file cannot leave partial data behind.

## Behavior

`fxrates load <csv>` returns exit code `3` for a file with a wrong row width, an invalid or repeated date, or an invalid or zero rate. It writes no standard output and emits one diagnostic line to standard error.

A rejected file leaves all previously stored rates unchanged. The loader uses the shared persistence operations declared in `DATABASE.md`.

# FEATURE: Fetch History

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Fetch the ECB history archive and load its CSV through the shared history loader. |
| Depends On  | FEATURE-Load-History.md, DATABASE.md |
| Provides    | fxrates fetch |
| Consumes    | fxrates load, rates repository operations |

## Questions

- None.

## Purpose

`fxrates fetch` retrieves the ECB history ZIP archive, extracts `eurofxref-hist.csv`, and loads it using the same validation, replacement, storage, and reporting behavior as `fxrates load`.

## Workflow

The download boundary is a callable `download_archive(destination)` in `cli.fetch`. It writes the downloaded archive to the supplied destination. Keep this boundary replaceable so automated tests can provide a local ZIP archive without network access.

The command extracts the named CSV to a temporary location and passes that file to the shared loader. A download failure returns exit code `1`; invalid extracted history follows the loader's rejection behavior.

## Programmatic Acceptance

=== AC fetch-loads-stubbed-archive ===
Intent: Fetch loads an ECB-format CSV from a locally supplied archive without opening a network connection.

import tempfile
import zipfile
from unittest.mock import patch

from cli.testing import cli_runner
from persistence.testing import committed_session

date = "2099-01-07"
currency = "ZZU"
rate = "7.890"

with tempfile.TemporaryDirectory() as directory:
    archive = f"{directory}/history.zip"
    with zipfile.ZipFile(archive, "w") as output:
        output.writestr(
            "eurofxref-hist.csv",
            f"Date,{currency},\n{date},{rate},\n",
        )

    def stub_download(destination):
        with open(archive, "rb") as source, open(destination, "wb") as target:
            target.write(source.read())

    try:
        with patch("cli.fetch.download_archive", side_effect=stub_download):
            code, stdout, stderr = cli_runner("fetch")
        assert code == 0
        with committed_session() as db:
            row = db.rates.get(date=date, currency=currency)
            assert row is not None
            assert row.rate == rate
    finally:
        with committed_session() as db:
            db.rates.delete(date=date, currency=currency)

## Purpose

Expose a health response and statistics derived from the rates currently stored. Statistics include the number of distinct publication dates with rates, the total number of stored rates, and the first and last publication dates. Empty stores report null date bounds.

# FEATURE: Rates

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Return all rates for the latest publication on or before a requested date. |
| Depends On  | FEATURE-API-Foundation.md, DATABASE.md |
| Provides    | GET /rates/{date}, GET /rates/latest |
| Consumes    | rates repository operations |

## Questions

- None.

## Purpose

Rates are units of currency per euro. A request for date `D` selects the latest publication date on or before `D` and returns every rate stored for that publication. `/rates/latest` selects the latest stored publication and echoes `"latest"` as its requested value. A request with no eligible publication returns HTTP 404.

## Routes

- `GET /rates/{date}` accepts a real calendar date in `YYYY-MM-DD` form.
- `GET /rates/latest` returns the latest publication.

## Programmatic Acceptance
