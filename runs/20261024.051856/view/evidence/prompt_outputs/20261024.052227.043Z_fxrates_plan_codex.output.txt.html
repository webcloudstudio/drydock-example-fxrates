# FEATURE: CLI Usage

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Defines usage errors for unsupported or malformed `fxrates` invocations. |
| Depends On  | FEATURE-CLI-Foundation.md |
| Provides    | CLI usage error behavior |
| Consumes    | ./fxrates entry point |

## Questions

- None.

## Purpose

Return exit code `2` for unknown commands, incorrect argument counts, and a non-integer port value. These usage failures produce no standard output. Write a single diagnostic line to standard error.

## Trigger and behavior

The root `./fxrates` executable dispatches commands. It rejects an unrecognized command, a command with the wrong number of arguments, or `serve --port` followed by a non-integer value with exit code `2`.

## Programmatic Acceptance

=== AC usage-unknown-command ===
Intent: An unknown command returns the usage exit status.

from cli.testing import cli_runner

code, stdout, stderr = cli_runner("frobnicate")
assert code == 2
assert stdout == ""
=== END AC usage-unknown-command ===

=== AC usage-wrong-arguments ===
Intent: A command missing its required argument returns the usage exit status.

from cli.testing import cli_runner

code, stdout, stderr = cli_runner("load")
assert code == 2
assert stdout == ""
=== END AC usage-wrong-arguments ===

=== AC usage-invalid-port ===
Intent: A non-integer port returns the usage exit status.

from cli.testing import cli_runner

code, stdout, stderr = cli_runner("serve", "--port", "notaport")
assert code == 2
assert stdout == ""
=== END AC usage-invalid-port ===

## User Acceptance

- None.

## Guardrails

- Usage failures use exit code `2` and produce no standard output.

# FEATURE: Serve HTTP API

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Runs the FastAPI service on localhost until it is stopped. |
| Depends On  | FEATURE-CLI-Foundation.md, FEATURE-API-Foundation.md |
| Provides    | fxrates serve |
| Consumes    | app_server.main:create_app |

## Questions

- None.

## Purpose

The `fxrates serve` command starts uvicorn in the foreground, bound only to `127.0.0.1`. It accepts an optional integer port and defaults to port `8000`. The process stops cleanly on SIGTERM.

## Trigger and behavior

Running `./fxrates serve` starts the service on `127.0.0.1:8000`. Running `./fxrates serve --port <n>` starts it on `127.0.0.1:<n>`. The API application is supplied by `app_server.main:create_app`.

## Programmatic Acceptance

=== AC serve-command-entry ===
Intent: The CLI exposes the serve command.

from cli import main

assert callable(main)
=== END AC serve-command-entry ===

=== AC serve-app-factory ===
Intent: The server command's application factory is available.

assert callable(create_app)
=== END AC serve-app-factory ===

## User Acceptance

- None.

## Guardrails

- Bind to `127.0.0.1`; use port `8000` when none is supplied.
- Run in the foreground and stop cleanly on SIGTERM.

## Questions

- None.

## Purpose

The completed application provides `bin/test.sh`, a POSIX-compatible launcher that runs the project's pytest suite from the application root and succeeds only when every test passes. The supplied `sources/run.sh` is an authoritative full-project grader. This story is the terminal full-suite gate, after all implementation stories are complete.

The grader sets `DATABASE_URL` to a fresh temporary SQLite file, exercises CLI commands, starts the local server, and checks its HTTP responses. It does not exercise `fetch` and makes no network requests beyond localhost.

## Verification behavior

Keep the supplied grader and its CSV fixtures unchanged. The full grader is run only by this terminal story. The project's test suite covers each command, each CSV load rule, each endpoint, effective-date selection, rounding, and error statuses; tests of `fetch` stub the download and use no network.
